# Changelog

- Send a source field to alternative storage instead of a target field: double-click an unmapped source field to mark that its value goes to e.g. the PDF the migration tool generates, then name the storage via "Oplossen" — the name already in use is pre-filled, other names in use are suggested, and a casing variant (`pdf` vs `PDF`) shows a warning. The canvas shows a dot at the source field, the Koppelingspaneel shows "—" with a warning until named and a name pill after. The export writes such a coupling with `"targetField": null` and `"alternativeStorage": "<naam>"`; `targetField` can therefore now be `null` for consumers of the export ([#194](https://github.com/ICATT-Menselijk-Digitaal/Mapping-Assistant/issues/194))
- Faster field hover and smoother scrolling on large coupling sets: hovering a field now only redraws the rows whose highlight changes, moving from one field to the next is a single update (no flicker of the connection lines in between), and repositioning the connection lines while scrolling no longer searches the whole page per line. On the real DET → OpenZaak set at 4× CPU throttling, the median hover went from 104 ms to 32 ms with no hover over 100 ms, and scroll frames over 50 ms went from 60 of 60 to 2 of 60. Includes two importable test datasets and a measuring script (`npm run perf:hover`) ([#195](https://github.com/ICATT-Menselijk-Digitaal/Mapping-Assistant/issues/195))
- Inspect enum field constraints in the schema panel: enum fields display an "enum" tag alongside their base type (e.g. "string") instead of the generic "obj" tag, are not expandable, and expose their allowed values as "Can contain '…', '…'" in the collapsible description section — alone when the field has no own description, or below it otherwise ([#181](https://github.com/ICATT-Menselijk-Digitaal/Mapping-Assistant/issues/181))
- Add a comment to a Koppeling: record a short, timestamped note from its detail view, see a row-level indicator with a hover preview in the Koppelingen paneel, filter the paneel to only Koppelingen with a comment, and have the comment carried through export/import ([#161](https://github.com/ICATT-Menselijk-Digitaal/Mapping-Assistant/issues/161))
- Filter the Koppelingen paneel by resolution status (Alle / Actie vereist), combined with the existing field-name search ([#142](https://github.com/ICATT-Menselijk-Digitaal/Mapping-Assistant/issues/142))
